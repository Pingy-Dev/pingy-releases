## Features

**Protocols** — VLESS with XTLS Vision, VMess, Trojan, Shadowsocks, Hysteria2, WireGuard, AmneziaWG 3.1, SOCKS5 and HTTP.

**Obfuscation** — Reality, TLS 1.3 with browser fingerprints, XHTTP, gRPC, WebSocket, HTTPUpgrade, mKCP.

**Subscriptions** — Remnawave, Marzban, 3x-ui, plain link lists, base64, Clash YAML and sing-box JSON. Single keys can be pasted one at a time.

**Control** — Automatic fastest-server selection, per-app split tunnelling, custom routing rules, DNS profiles and provider branding.

[Full protocol list →](https://pingy.top/#protocols) · [Provider documentation →](https://pingy.top/docs)
