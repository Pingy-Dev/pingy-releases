## Можливості

**Підключення** — VLESS з XTLS Vision, VMess, Trojan, Shadowsocks, Hysteria2, WireGuard, AmneziaWG 3.1, SOCKS5 і HTTP.

**Маскування** — Reality, TLS 1.3 з відбитками браузерів, XHTTP, gRPC, WebSocket, HTTPUpgrade, mKCP.

**Підписки** — Remnawave, Marzban, 3x-ui, список посилань, base64, Clash YAML і sing-box JSON. Окремі ключі вставляються по одному.

**Керування** — Автовибір швидкого сервера, роздільне тунелювання за застосунками, власні правила маршрутизації, DNS-профілі та оформлення провайдера.
