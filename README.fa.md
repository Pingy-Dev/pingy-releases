## امکانات

**پروتکل‌ها** — VLESS با XTLS Vision، VMess، Trojan، Shadowsocks، Hysteria2، WireGuard، AmneziaWG 3.1، SOCKS5 و HTTP.

**پنهان‌سازی** — Reality، TLS 1.3 با اثر انگشت مرورگرها، XHTTP، gRPC، WebSocket، HTTPUpgrade، mKCP.

**اشتراک‌ها** — Remnawave، Marzban، 3x-ui، فهرست ساده لینک‌ها، base64، Clash YAML و sing-box JSON. کلیدهای تکی را می‌توان یکی‌یکی وارد کرد.

**کنترل** — انتخاب خودکار سریع‌ترین سرور، تونل تفکیکی بر اساس برنامه، قوانین مسیریابی دلخواه، پروفایل‌های DNS و ظاهر اختصاصی ارائه‌دهنده.

[فهرست کامل پروتکل‌ها →](https://pingy.top/#protocols) · [مستندات ارائه‌دهندگان →](https://pingy.top/docs)
