## 功能

**协议** — VLESS（支持 XTLS Vision）、VMess、Trojan、Shadowsocks、Hysteria2、WireGuard、AmneziaWG 3.1、SOCKS5 和 HTTP。

**伪装** — Reality、带浏览器指纹的 TLS 1.3、XHTTP、gRPC、WebSocket、HTTPUpgrade、mKCP。

**订阅** — Remnawave、Marzban、3x-ui、纯链接列表、base64、Clash YAML 和 sing-box JSON。单条密钥也可逐个粘贴。

**控制** — 自动选择最快服务器、按应用分流、自定义路由规则、DNS 配置以及服务商主题。
